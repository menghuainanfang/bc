# Skill 需求定义卡

## Skill 1：信贷财报多表交叉核验助手

| 维度 | 内容 |
|---|---|
| **1. Skill 名称** | 信贷财报多表交叉核验助手 |
| **2. 目标用户** | 银行对公信贷审查员（初级/中级）、小贷公司风控分析师、审计事务所初级审计员 |
| **3. 对应赛题类别** | 智能文档解析 |
| **4. 对应覆盖赛题** | 金融材料智能解析与风险洞察 |
| **5. 关键词和价值点** | 关键词：财报解析、勾稽校验、风险标签、现金流分析、信贷审核；价值点：将30+项指标提取从2小时压缩到10分钟，勾稽矛盾零遗漏，新人也能达到资深审查员的交叉核验水平 |
| **6. 真实使用场景** | 审查员收到企业贷款申请材料（含近三年审计报告PDF），需在2小时内完成财务分析章节。打开Skill，上传三张报表PDF，自动提取指标、校验勾稽关系、标注风险点，生成财务分析初稿 |
| **7. 用户输入** | 企业近三年资产负债表、利润表、现金流量表PDF文件（每年3张，共3-9个文件）；可选：审计报告PDF、征信报告摘要 |
| **8. Skill 输出** | ①结构化「关键财务指标提取表」（≥30项，含同比/环比变化）；②「表间勾稽关系校验报告」（逐项标注一致/不一致/待核实）；③「现金流健康度评级」（A/B/C/D四档+依据）；④「风险标签清单」（如：应收账款增速远超营收增速、经营性现金流持续为负、存货周转天数异常上升等） |
| **9. 标准工作流程** | 见下方流程图 |
| **10. 触发词** | 核查财报、分析财务报表、检查勾稽关系、财报风险识别、信贷审核、查企业财务异常、核对三张报表、看财报有没有问题、财务造假识别、报表勾稽校验、帮我审一下这家企业的财报 |
| **11. 结果验收标准** | ①指标提取准确率≥95%（与人工提取对比）；②三张表间核心勾稽关系（净利润与未分配利润变动、销售收入与经营性现金流入、折旧与固定资产变动等）全部校验，零遗漏；③风险标签有具体数值支撑，不凭空断言；④不确定处明确标注「待人工核实」 |
| **12. 不应该做什么** | ①不给出「建议批准/拒绝贷款」等信贷决策；②不伪造或猜测任何财务数据；③不对审计报告出具审计意见；④不替代人工的专业判断，定位于「提效工具」而非「决策工具」 |

---

## 标准工作流程

```
用户上传三张报表PDF
       ↓
[步骤1] 财报解析：OCR识别 + 表格结构提取，输出结构化JSON
       ↓
[步骤2] 指标提取：从三张表中提取≥30项关键财务指标，计算同比/环比
       ↓
[步骤3] 勾稽校验：逐项交叉验证——
         · 净利润(利润表) ↔ 未分配利润变动(资产负债表)
         · 销售收入(利润表) ↔ 经营性现金流入(现金流量表)
         · 折旧摊销(现金流量表) ↔ 固定资产/无形资产变动(资产负债表)
         · …等8大核心勾稽关系
       ↓
[步骤4] 现金流分析：评估经营活动/投资活动/筹资活动现金流结构健康度
       ↓
[步骤5] 风险标注：基于指标异常 + 勾稽矛盾 + 现金流异常，生成风险标签
       ↓
输出：指标提取表 + 勾稽校验报告 + 现金流评级 + 风险标签清单
```
