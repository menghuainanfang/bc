# Skill 需求定义卡

## Skill 2：体检化验单异常分级解读助手

| 维度 | 内容 |
|---|---|
| **1. Skill 名称** | 体检化验单异常分级解读助手 |
| **2. 目标用户** | 基层社区卫生服务中心全科医生、家庭医生团队成员、体检中心报告解读员、关注自身健康的体检者（自助初筛） |
| **3. 对应赛题类别** | 智能文档解析 |
| **4. 对应覆盖赛题** | 医疗健康智能理解与辅助决策 |
| **5. 关键词和价值点** | 关键词：体检报告解读、化验单分析、异常指标分级、危急值提醒、检后管理；价值点：将体检报告解读从15分钟/份压缩到2分钟/份，异常指标按"危急/需关注/观察"三级智能分级，基层医生临床判断有据可依，减少"只检不管" |
| **6. 真实使用场景** | 体检季到来，社区卫生中心每天收到100+份居民体检报告。家庭医生打开Skill，上传体检报告PDF，自动获取异常指标分级汇总、临床意义解读和建议就诊方向，医生据此快速完成"一对一报告解读"入户服务 |
| **7. 用户输入** | 居民体检报告PDF/清晰图片（含血常规、尿常规、生化全套、肿瘤标志物、甲状腺功能、B超/心电图文字报告等），单份或多份皆可 |
| **8. Skill 输出** | ①「异常指标分级汇总表」（危急🔴/需关注🟡/观察🟢 三级，含参考区间和实测值）；②「临床意义解读」（每个异常指标的可能原因，标注常见/少见/需排除）；③「建议行动」（复查项目+建议就诊科室+生活干预建议）；④「慢病管理提示」（符合高血压/糖尿病/高脂血症等慢病管理标准的指标，提示纳入管理） |
| **9. 标准工作流程** | 见下方 |
| **10. 触发词** | 解读体检报告、帮我看化验单、体检异常什么意思、帮我看看这个指标、血常规分析、生化全套解读、体检报告看不懂、指标箭头什么意思、化验单异常、体检结果分析、帮我读一下这份体检报告 |
| **11. 结果验收标准** | ①所有偏离参考区间的指标100%收录，无遗漏；②危急值（如血钾>6.5mmol/L、血糖<2.8mmol/L等）强制最高级提醒；③临床解读有据（引用临床指南或检验医学共识），不凭空推测；④明确标注「本解读为辅助工具，最终诊断请以执业医师意见为准」 |
| **12. 不应该做什么** | ①不给确诊结论；②不开处方；③不对影像图片（X光/CT/MRI）做直接判读（仅解读文字报告部分）；④不替代执业医师的最终判断；⑤不存储或外传患者个人身份信息 |
