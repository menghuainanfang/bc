# Skill 需求定义卡

## Skill 3：多源材料交叉溯源验证助手

| 维度 | 内容 |
|---|---|
| **1. Skill 名称** | 多源材料交叉溯源验证助手 |
| **2. 目标用户** | 行业研究员、政策分析师、硕士研究生（撰写综述或研究报告）、尽职调查分析师、新闻事实核查员 |
| **3. 对应赛题类别** | 智能文档解析 |
| **4. 对应覆盖赛题** | 多源信息检索与分析 |
| **5. 关键词和价值点** | 关键词：多源检索、交叉验证、来源追溯、综述、信息可信度分级、事实核查；价值点：终结"AI编造引用"问题——每条结论必须指向具体来源+段落位置，信息冲突自动标注，可信度三级分级（一手数据/二手转引/未溯源），将综述写作从100+小时压缩到半天 |
| **6. 真实使用场景** | 研究员接到任务「3天内出一份某行业竞争格局报告」。他打开Skill，输入研究主题，上传已收集的5份行业报告PDF+3篇论文PDF+2篇新闻链接，Skill自动提取各来源关键信息，按主题维度组织，标注来源冲突和可信度，生成带完整来源追溯的报告初稿 |
| **7. 用户输入** | ①研究主题/问题（必填）；②多来源文件（PDF/Word/网页链接，≥2个来源，建议3-10个）；③可选：分析角度偏好（如：市场规模、竞争格局、技术路线、政策环境等） |
| **8. Skill 输出** | ①「信息来源清单」（每个来源的基本信息+可信度预评级）；②「多源信息交叉矩阵」（行=关键主题/问题，列=各来源，交叉格=该来源的相关内容摘要+位置标注）；③「信息一致性分析」（一致结论/互补信息/矛盾冲突 三类标注）；④「综合报告」（按主题维度组织的叙述性报告，每句可追溯到具体来源）；⑤「未溯源断言清单」（综合报告中无法追溯到原始来源的推断性结论） |
| **9. 标准工作流程** | 见下方 |
| **10. 触发词** | 多源信息分析、交叉验证、综述、信息来源追溯、信息可信度核查、帮我对比这几份报告、查一下信息是否一致、多来源交叉比对、这些报告说的对不对、事实核查、文献综述、帮我梳理这些材料 |
| **11. 结果验收标准** | ①每条结论可追溯到具体来源+位置（段落/页码）；②信息矛盾100%标注，不做主观调和；③无可溯源来源的推断性结论强制列入「未溯源断言清单」；④不编造来源、标题、数据 |
| **12. 不应该做什么** | ①不编造任何引用（论文标题、作者、数据等）；②不在信息冲突时替用户选择相信哪一方（只标注差异，不做裁决）；③不跳过来源标注（每个关键结论必须有源）；④不对未读的来源做假设性引用；⑤不输出无来源支撑的主观观点 |
