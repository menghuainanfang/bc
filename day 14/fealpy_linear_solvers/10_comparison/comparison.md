# 综合对比 —— 同一 SPD 矩阵上的所有求解器

## 目的

对同一个 $50 \times 50$ 的 SPD 矩阵（1D Poisson 离散），用所有 9 种求解器求解，并排对比迭代次数和残差。

## 精确解设计

为展示迭代法的真实收敛行为（而非单一特征向量的退化特例），精确解选用：

$$u(x) = \sin(\pi x) + 0.5\sin(3\pi x)$$

该解**同时包含第 1 和第 3 特征模态**，因此 Krylov 子空间需要恰好 2 维才能精确表示——CG 等 Krylov 方法需要 2 步收敛。

若使用单一特征向量（如 $\sin(\pi x)$），CG 会 1 步收敛，无法展示正常行为。

## 结果解读

| 现象 | 原因 |
|------|------|
| Krylov 方法均 2-3 步收敛 | 精确解仅含 2 个特征模态 → Krylov 子空间恰好 2 维 |
| spsolve 残差 ~1e-12 | 直接法 = 机器精度 |
| Jacobi 5000 步未收敛 | 谱半径 $\rho_J = \cos(\pi h) \approx 0.998$，衰减极慢 |
| GS 需 ~4400 步 | 谱半径 $\rho_{GS} = \rho_J^2 \approx 0.996$，比 Jacobi 快一倍但仍远慢于 Krylov |

## 选型结论

```
矩阵类型           推荐求解器
─────────────────────────────
SPD               cg（首选）
对称不定           minres
一般非对称         bicgstab / gmres
任意（小规模）      spsolve（基准）
大规模 SPD         cg + 多重网格预条件
```
