# 勒贝格控制收敛定理 (DCT)

---

## 一、要点

> 学习时暴露的真实盲区。

1. **Fatou 引理的 liminf 是逐点取的**——之前和集合版上下极限列搞混了。扑克牌类比（"先取最小再处理 ≤ 先处理再取最小"）直觉对，但需要记住 $(\liminf f_n)(x) = \liminf_{n\to\infty} f_n(x)$
2. **$1/\sqrt{x}$ 在 $[0,1]$ 上的可积性**——黎曼框架下无界 → 不是正常黎曼可积（是瑕积分）。勒贝格框架下 $\int_0^1 1/\sqrt{x}\,dx = 2 < \infty$ → 勒贝格可积。**无界函数可以勒贝格可积**，只要总面积有限
3. **DCT 证明中 $g$ 的可积性在消去 $\int g$ 时是必须的**——若 $\int g = \infty$，$\int g - \int f_n$ 变成 $\infty - \infty$，非法操作
4. 控制条件是**逐点控制**（$|f_n(x)| \leq g(x)$ a.e.）而非积分控制——$g$ 要压住每一个 $f_n$ 的每一点，而不只是 $\int|f_n|$ 被 $\int g$ 控制

### M1：问题起源 — 为什么需要 DCT？

- **核心内容**：一致收敛能保证极限与积分交换，但它对"每一点都乖"的要求太敏感——即使只在一个零测点上出问题（如 $f_n(0)=n\to\infty$），也可能破坏一致收敛。DCT 把条件从"每一点都乖"放松到"几乎处处被可积函数控制"。
  - 对比案例：$f_n$（尖峰，$\int f_n = 1 \not\to 0$，无控制函数）vs $x^n$（$\int x^n = 1/(n+1) \to 0$，有控制函数 $g\equiv 1$）
  - 两者都不一致收敛，但决定能否交换的不是一致收敛，是**有没有可积控制函数**

- **关键收获**：能回答"如果不用 DCT，极限积分交换被什么条件卡住？"
- **逻辑连接**：← 出发点 / → M2：DCT 的三个条件直接回应了 M1 的问题

---

### M2：定理陈述 — DCT 说了什么？

- **核心内容**：设 $\{f_n\}$ 可测——
  - **C1**：$f_n \to f$ a.e.（允许零测集上的坏行为，对应线索2✅）
  - **C2**：存在可积 $g$（$\int g < \infty$）使 $|f_n| \leq g$ a.e.，对所有 $n$
  - 结论：$\lim_n \int f_n = \int f$，且更强地 $\int|f_n-f| \to 0$（$L^1$ 收敛）
  - **无界函数可勒贝格可积**（线索4⚠️）：$1/\sqrt{x}$ 在 $[0,1]$ 上无界 → 非黎曼可积，但 $\int_0^1 1/\sqrt{x}=2<\infty$ → 勒贝格可积。DCT 的控制函数 $g$ 可以有奇点

- **关键收获**：能写出 C1+C2，解释 C2 为什么蕴含了每个 $f_n$ 可积
- **逻辑连接**：← M1 / → M3：两个条件在证明中各有分工

---

### M3：证明拆解 — DCT 为什么正确？

- **核心内容**：Fatou 引理（单向 $\leq$）+ 双向构造（$g\pm f_n \geq 0$）= 双向相等。
  - 第2步（$g-f_n$）：$\limsup\int f_n \leq \int f$
  - 第3步（$g+f_n$）：$\int f \leq \liminf\int f_n$
  - 第4步：$\liminf \leq \limsup$ 恒成立 → 全部相等 → $\lim\int f_n = \int f$
  - **Fatou 引理的 $\liminf$ 是逐点取的**（线索3⚠️）：$(\liminf f_n)(x) = \liminf_{n\to\infty} f_n(x)$。直觉"先取最小再积分 ≤ 先积分再取最小"方向正确
  - **$g$ 可积在消去 $\int g$ 时是安全许可**：若 $\int g = \infty$，$\int g - \int f_n = \infty - \infty$ 非法
  - 控制函数 $g$ 的三重角色：非负化器（$g\pm f_n \geq 0$）、消去项（$\int g$ 抵消）、庇护所（允许 $f_n$ 有奇点）

- **关键收获**：能独立复述双向夹逼结构，解释 $g$ 可积在消去步骤的不可替代性
- **逻辑连接**：← M2 / → M4：验证 DCT 条件的标准流程

---

### M4：典型实例 — DCT 怎么用？

- **核心内容**：标准操作——验 C1 → 找控制函数 → 验 $\int g < \infty$ → 放心交换。
  - 实例1：$f_n = nx/(1+n^2x^2)$ on $[0,1]$。AM-GM → $|f_n| \leq 1/2$，$g\equiv 1/2$ → DCT 适用
  - 实例2：$f_n = \sin(nx)/(n\sqrt{x})$ on $[0,1]$。$|f_n| \leq 1/\sqrt{x}$ → **$\int_0^1 1/\sqrt{x}=2<\infty$**（线索4）→ DCT 适用
  - 常见 $g$ 的套路：常函数（一致有界时）、$C/|x|^\alpha$（$\alpha<1$，原点奇点）、$Ce^{-ax}$（无穷区间衰减）、$C/(1+|x|^\alpha)$（$\alpha>1$，无穷区间）

- **关键收获**：能独立判断一个函数序列是否适用 DCT，并找到控制函数
- **逻辑连接**：← M3 / → M5：DCT 在收敛定理谱系中的位置

---

### M5：定理谱系 — DCT 在实分析中的位置

- **核心内容**：三大收敛定理——Fatou（最弱前提，单向 $\leq$）→ MCT（单调保证收敛）→ DCT（需要控制函数，最强结论）。三者构成逻辑等价三角。
  - **Fatou**：非负函数列，$\int\liminf f_n \leq \liminf\int f_n$。不需要预先知道收敛——$\liminf$ 永远存在
  - **MCT**：非负单调递增，$\lim\int f_n = \int \lim f_n$。单调性既是收敛保证也是控制手段（$f$ 天然是 $g$）
  - **DCT**：a.e.收敛 + 可积控制 → 双向相等。Fatou + 双向构造 = DCT
  - 选哪个取决于条件：单调 → MCT；只知非负 → Fatou；可找到控制函数 → DCT

- **关键收获**：能画出三者的逻辑依赖图，为任意场景选择最合适的定理
- **逻辑连接**：← M4 / 终点

## 快速回顾问题

1. DCT 的两个条件是什么？为什么 C2 蕴含了每个 $f_n$ 都可积？
2. DCT 证明中，$g-f_n$ 和 $g+f_n$ 分别用 Fatou 得到什么不等式？两个不等式怎么逼出等号？
3. $g$ 可积（$\int g < \infty$）在证明的哪一步不可替代？如果 $\int g = \infty$ 会怎样？
4. $f_n(x) = n/(1+n^2x^2)$ on $[0,1]$——DCT 适用吗？如果适用，写出控制函数。
5. Fatou、MCT、DCT 三者的逻辑依赖关系是什么？面对一个具体问题，怎么选？
6. $1/\sqrt{x}$ 在 $[0,1]$ 上黎曼可积吗？勒贝格可积吗？为什么这个区分对理解 DCT 的控制函数很重要？
7. 举一个例子：$f_n \to 0$ a.e.，每个 $f_n$ 可积，但 DCT 不适用。为什么？
