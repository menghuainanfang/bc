# 数值计算作业批改量规

> 本量规为 Skill 在批改数值计算作业时提供判定标准和误差容忍度参考。

---

## 一、通用判定维度

| 维度 | 权重建议 | 检查要点 |
|------|---------|----------|
| 算法正确性 | 50% | 数值方法的核心迭代公式是否正确实现 |
| 数值精度 | 25% | 结果误差是否在合理范围内 |
| 代码规范 | 15% | 变量命名清晰、有适当注释、无硬编码魔法数字 |
| 鲁棒性 | 10% | 对不同输入的适应性、边界条件处理 |

---

## 二、分方法类型的误差容忍度

### 2.1 线性方程组直接法（LU、Cholesky、QR）

**检查方法**：计算残差 `||Ax - b|| / ||b||`
**可接受范围**：< 1e-10（双精度下应接近机器精度）
**常见扣分**：
- 自己实现 LU 分解但未做选主元（导致数值不稳定）
- Cholesky 分解前未检查对称正定性

### 2.2 线性方程组迭代法（Jacobi、Gauss-Seidel、SOR、CG）

**检查方法**：
1. 计算最终的 `||Ax - b|| / ||b||`
2. 检查迭代次数是否合理（应在几百次以内收敛）
**可接受范围**：残差 < tol 设置值
**常见扣分**：
- Jacobi 迭代中误用了更新后的值
- SOR 的松弛因子 omega 设置不合理（应 0 < omega < 2）
- 未设置 max_iter 上限保护

### 2.3 数值积分（梯形、Simpson、Gauss 求积）

**检查方法**：
1. 对被积函数 f(x)=x^k 测试（k 次的多项式应有精确结果）
2. 检查不同步长下的收敛阶

| 方法 | 对多项式的精确阶 | 收敛阶 |
|------|-----------------|--------|
| 复合梯形 | 1 次 | O(h^2) |
| 复合 Simpson | 3 次 | O(h^4) |
| Gauss-Legendre (n 点) | 2n-1 次 | - |

**可接受范围**：当步长 h=0.01 时，梯形法则相对误差 < 1e-4，Simpson < 1e-8

### 2.4 ODE 初值问题求解

**检查方法**：
1. 用有解析解的简单 ODE 测试（如 y' = y, y(0) = 1）
2. 检查不同步长下误差的收敛阶

| 方法 | 局部截断误差 | 全局收敛阶 |
|------|------------|-----------|
| Euler | O(h^2) | O(h) |
| RK2/中点法 | O(h^3) | O(h^2) |
| RK4 | O(h^5) | O(h^4) |

**可接受范围**：在步长 h=0.1 时——
- Euler 法相对误差 < 5%
- RK4 相对误差 < 1e-4

### 2.5 插值与拟合

**检查方法**：
1. 插值：在被插值点上是否精确等于已知值（误差 < 1e-12）
2. 拟合：检查残差平方和是否合理

**常见扣分**：
- Lagrange 插值多项式中的分母遗漏
- 三次样条缺少边界条件
- 最小二乘的正规方程条件数过大时未做处理

### 2.6 特征值问题

**检查方法**：
1. 计算 `||Ax - λx||` 检验特征对
2. 对比 `np.linalg.eig` 的结果（作为参考，不作为唯一标准）

**可接受范围**：`||Ax - λx|| < 1e-8`（对于 n < 100 的矩阵）

## 三、学生常见错误分类

### A 类：算法逻辑错误（严重影响结果）
- 核心公式写错（如系数、权重、迭代关系）
- 遗漏关键步骤（如未选主元的 LU 分解）
- 方法用错（如用左矩形代替梯形法则）

### B 类：边界/初始条件错误（结果部分正确）
- ODE 求解中遗漏了初始值
- 有限差分未正确处理边界节点
- 数值积分的积分区间端点遗漏

### C 类：数值精度问题（结果大致正确但不精确）
- 步长过大
- 收敛容差设置不当
- 数据类型错误（用 int 而非 float）

### D 类：代码实现问题（能运行但效率低）
- 不必要的循环（应向量化但未向量化）
- 重复计算相同值
- 数组预分配不当

### E 类：输入输出格式问题
- 函数签名与题目要求不符
- 返回值格式不一致

## 四、反馈措辞指南

在生成针对学生的个性化反馈时，遵循以下原则：

1. **先肯定再指出问题**："你的整体思路是正确的，用 Gauss-Seidel 迭代求解的思路很好。但有一个细节需要注意……"
2. **具体指向而非笼统批评**：不说"代码写得太差了"，而说"第 15 行的权重系数应该是 4 而非 2，这导致你的 Simpson 积分精度没有达到预期"
3. **给出可操作的改进方向**："建议用 f(x)=x^3 测试一下你的 Simpson 积分代码——理论上应该得到精确结果（误差 < 1e-12），如果不是，说明权重系数有问题"
4. **对精度问题说明物理意义**："1% 的相对误差在实际工程中可能可以接受，但在本题要求的精度下还需要更小的步长"
